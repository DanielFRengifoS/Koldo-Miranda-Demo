# Koldo Miranda · Etapa 05 · Opción 03

Demo estática de exploración de dos territorios gastronómicos. Abrir `index.html` directamente en un navegador moderno.

- No requiere servidor, dependencias ni conexión a internet.
- Las dos ilustraciones SVG son originales y locales.
- La selección de una ruta muestra un bloque contextual; los detalles y la comparación también permanecen accesibles mediante enlaces internos.
- No hay reservas, formularios, disponibilidad, pagos ni envío de datos.
- Uso exclusivo interno. No publicar ni enviar.

Consulta `NOTAS_05.md` para procedencia, decisiones editoriales y límites de verificación.
